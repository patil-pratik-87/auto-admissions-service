# Tools

Neither tool is part of the service, and nothing here is imported by `app/`.

- [rule-extractor/](rule-extractor/) drafts YAML rules from the policy handbook, so a new
  program starts from a draft rather than a blank file. Every rule still needs human approval.
- [sample-builder/](sample-builder/) turns a persona YAML file into the applicant PDFs in
  [../samples/filled-documents/](../samples/filled-documents/).
